# NPC Lifecycle — программа минимум

Три фазы оживления НПС. Каждая самодостаточна — после любой фазы игра уже играбельна.

## Фаза 1 — Расписание оживает (0 LLM, чистые правила)

Сейчас `location_label` — просто строка-метка. Нужно чтобы она **реально влияла на геймплей**.

### Суб-локации

Регион (например "Вайтран") содержит именованные точки: tavern, market, smithy, barracks, gate. Игрок и НПС находятся в одной из них. `look` показывает только тех, кто в той же суб-локации.

- Пришёл на рынок в 10 утра → видишь торговца и фермера.
- Пришёл в 22:00 → рынок пуст, все в таверне.

### Недоступность

Стучишь к кузнецу ночью → "Кузница закрыта, из дома слышен храп". Шаблон по `activity`, без LLM.

### Флейвор-строки

При `look` рядом с НПС: "Грунд работает у наковальни" / "Грунд сидит в таверне с кружкой эля". Словарь `{(role, activity) → flavor_text}`, без LLM.

**Итог:** мир чувствуется живым. Город пустеет ночью, утром оживает. Ноль LLM-вызовов.

## Фаза 2 — Память и осведомлённость (LLM при диалоге)

Когда игрок **заговаривает** с НПС — тот знает контекст.

### Event digest

Перед LLM-вызовом собираем что произошло в регионе с последнего разговора. Уже есть через `get_perceived_log`, нужно скармливать в промпт.

### conversation_summary

После диалога LLM генерирует 1-2 строки summary → сохраняется на НПС. При следующем разговоре — в контексте. Поле уже есть, нужно подключить.

### RuleBrain-заглушка для диалога

Без LLM — canned response по роли и activity: "Покупать будешь?" (merchant+working), "Проваливай, я занят" (guard+working), "Zzz..." (sleeping).

**Итог:** НПС помнят, что было. Без LLM — минимальные но осмысленные реплики.

## Фаза 3 — Автономные тики ключевых НПС (L2)

### Тиры НПС

```python
class NpcTier(Enum):
    BACKGROUND = "background"   # L1: только расписание
    IMPORTANT  = "important"    # L2: реагирует на события
    KEY        = "key"          # L2+: периодические автономные тики
```

### Триггерный тик (IMPORTANT + KEY)

Мировое событие затрагивает НПС → один дешёвый LLM-вызов:

```
Ты кузнец Грунд. Характер: грубый, честный.
Произошло: объявлена война с орками.
Ответь JSON: {"schedule_change": "...", "mood": "...", "new_goal": "..."}
```

### Периодический тик (только KEY)

Раз в N игровых дней — тот же формат. Антагонист строит планы, компаньон развивается.

### Graceful degradation

Без LLM триггерные тики не срабатывают, НПС остаются на фазе 1. Игра работает, мир просто более статичный.

**Итог:** мир живёт без игрока. Вернулся через 3 месяца — кузнец ушёл в ополчение, торговец сбежал.
