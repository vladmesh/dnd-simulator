# Боевой режим

Обсуждение 2026-03-20.

## Проблема

Сейчас один набор tools (say/attack/idle) на все ситуации. LLM каждый ход
хаотично выбирает между разговором и атакой. В бою нужна структура.

## Два набора tools

### Вне боя (социальное взаимодействие)

```
say(text)          — говорить
idle()             — молчать
attack(target_id)  — удар → НАЧИНАЕТ БОЙ
```

### В бою

```
attack(target_id, description?)     — удар экипированным оружием
dodge(description?)                 — защитная стойка (disadvantage для атакующих)
disengage(description?)             — отступить без opportunity attack
dash(direction?, description?)      — двойное движение вместо атаки
move(toward | away_from | direction, description?)  — передвижение (до 30 ft)
flee(description?)                  — попытка убежать из боя
```

`description` — опциональный флейвор. "Замахиваюсь двуручным мечом сверху вниз",
"Отпрыгиваю за стол", "Бегу к двери и кричу: За Драконию!". Резолвер игнорирует,
но флейвор идёт в лог событий. Это закрывает потребность LLM "поговорить" в бою
без отдельного say-действия.

Нет отдельного `say` в бою. Хочешь что-то сказать — вписывай в description.

## Вход в бой

Первая атака → все в area переходят в боевой режим:

1. Атакующий бьёт (его атака резолвится нормально)
2. Все в area получают бросок инициативы
3. Порядок ходов фиксируется на весь бой
4. Набор tools переключается на боевой

## Инициатива

```python
def roll_initiative(creatures: list[Creature]) -> list[Creature]:
    rolls = [(c, roll_d20() + c.ability_scores.modifier(Ability.DEX)) for c in creatures]
    rolls.sort(key=lambda x: x[1], reverse=True)
    return [c for c, _ in rolls]
```

Порядок фиксируется. Ничья — по DEX modifier, потом случайно.

## Выход из боя

- **Все враги мертвы / сбежали** — но система не тегает "враг/союзник"
- **Механическое правило:** 2 раунда подряд без атак → бой окончен автоматически
- **flee()** — существо убегает, для него бой окончен
- **surrender** — позже, отдельная механика

Система не знает кто враг, кто союзник. В D&D 5e тоже нет жёсткого
механического разделения — это описательные понятия, DM решает из контекста.
LLM разбирается сама по промпту и логу событий.

## Позиционирование: 2D сетка

Каждое существо имеет позицию (x, y) на сетке area. 1 клетка = 5 ft.
Расстояние = евклидово (или манхэттенское, как в D&D).

### LLM не видит координаты

LLM получает **текстовое описание** через стороны света и дистанции:

```
Вокруг тебя:
- Варн (ранен, кинжал) — 15 ft на северо-западе
- Грок (здоров, дубина) — 5 ft на юге (вплотную)
- Элара (здорова, арбалет) — 40 ft на востоке
```

Конвертация из (dx, dy) → "на северо-западе" тривиальная:

```python
def direction_label(dx: int, dy: int) -> str:
    ns = "север" if dy > 0 else "юг" if dy < 0 else ""
    ew = "восток" if dx > 0 else "запад" if dx < 0 else ""
    if ns and ew:
        return f"на {ns}о-{ew}е"
    return f"на {ns or ew}е"
```

Каждое существо видит всё вокруг на 360° (как в D&D — нет понятия facing).
Отдельная механика видимости (туман, заклинания) может быть добавлена позже.

### Move через стороны света или к цели

LLM говорит:
- `move(toward="varn")` — подойти к Варну
- `move(away_from="varn")` — отойти от Варна
- `move(direction="north", distance=30)` — на 30 ft на север

Резолвер пересчитывает (x, y). Передвижение = speed (обычно 30 ft) за ход.

### Карта area

Минимально: размер area + стартовые позиции. Позже можно добавить
obstacles (стены, мебель) для укрытий и line of sight.

```yaml
# Пример
tavern:
  size: [40, 30]  # 40x30 ft
  obstacles:
    - type: table
      pos: [15, 10]
      cover: half
    - type: wall
      pos: [[0,0], [0,30]]  # западная стена
  spawn_points:
    player: [20, 15]
    npc_default: [10, 10]
```

### Этапы реализации сетки

| Этап | Что добавляем | Зависит от |
|------|--------------|------------|
| 1 | Позиции (x,y), расстояния, текстовое описание | Ничего |
| 2 | Move (подойти/отойти), reach проверка | Этап 1 |
| 3 | Obstacles, line of sight | Этап 2 |
| 4 | Pathfinding (A*) для move вокруг стен | Этап 3 |
| 5 | AoE (fireball area, cone) | Этап 1 |

## Боевой промпт

Промпт для NPC в бою сфокусирован — без погоды, политики, расписаний:

```
Ты — Варн Чёрная Рука, скупщик краденого. Ты в бою!

Характер: [personality]

Твоё состояние:
- HP: 12/18 (ранен)
- Оружие: кинжал (1d4 piercing)
- Скорость: 30 ft

Вокруг тебя:
- Полуорк со шрамом (id: player) — 10 ft на юге
- Грок (id: grok) — 20 ft на западе
- Элара (id: elara) — 35 ft на востоке

Последние события:
- Полуорк ударил тебя кинжалом (6 урона). "За Драконию!"
- Грок ударил тебя дубинкой (промах). "Варн, хватит!"

Раунд 3. Твой ход. Выбери действие.
```

## Opportunity Attack

При выходе из melee range (5 ft) без disengage — провоцирует
opportunity attack от всех враждебных существ в melee.

Резолвер проверяет автоматически при move. Не LLM решает —
система видит что существо вышло из range и даёт реакцию.

Для MVP можно пропустить, добавить позже.

## Что не тегается

- **Враг/союзник** — нет тегов. LLM решает из контекста промпта.
  AoE бьёт всех в зоне, огню пофиг кто друг кто враг.
- **Facing** — нет направления взгляда. Все видят на 360°.

## Открытые вопросы

- **Бонусные действия** — dual wield, некоторые заклинания. Для MVP не нужно?
- **Реакции** — opportunity attack, Shield. Как резолвить вне чьего-то хода?
- **Surrender** — как механически работает сдача? NPC перестаёт атаковать,
  выходит из боя? Или нужно согласие другой стороны?
- **Вход в бой для наблюдателей** — Элара не дралась, но рядом. Она в бою?
  Вариант: все в area попадают в initiative order, но могут idle/dodge.
