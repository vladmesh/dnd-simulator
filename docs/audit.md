## Notable (cross-referenced, not new)
- **`player-xp-not-persisted`** (backlogged **should**): confirmed. `PlayerCharacter.to_full_save_data()` (`core/player.py:74-113`) serializes name/race/class/level/hp/gold/items/class_features but **omits `experience` and `level_up_available`**. The modern autosave/reload path uses `to_full_save_data` + `parse_player`, so player XP resets to the content default (0) on reload. `load_save_data` (legacy `load_game` path, line 122-123) does read them, but `to_full_save_data` never writes them and `PlayerContent`/`_to_player` never read them. Fix: add the two fields to `to_full_save_data()` and `PlayerContent`/`_to_player`. Already filed — do not duplicate.
