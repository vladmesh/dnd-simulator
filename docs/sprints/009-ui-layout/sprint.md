# Sprint 009 — UI Layout & Inspect

**Goal:** Фиксированный viewport, форматированный лог, action bar с категориями, рабочая карточка NPC по кнопке "осмотреть".

**Started:** 2026-03-27

## Context

Sprint 008 довёл DM-сторону до рабочего состояния (schema-driven формы, каталоги, CRUD). Игровой экран не менялся с момента создания и имеет проблемы: лог растягивает страницу вниз, action bar — плоский список кнопок (не масштабируется при добавлении спеллов/классов), правая панель — статичный столбец. Кнопка "осмотреть" на NPC ничего не делает.

Перед расширением геймплея (спеллы, квесты, больше классов) UI должен уметь обрабатывать сложность: больше действий, больше событий в логе, больше информации о существах.

## Phase 1: Fixed Viewport + Log Formatting

Фиксированный layout на 100vh без глобального скролла. Event log — скроллируемый контейнер с auto-scroll. Табы на правой панели (вместо длинного списка). Форматирование лога: цветовое кодирование типов событий, заголовки ходов/раундов в бою, агрегация последовательных перемещений.

**Верифицируем:** Окно браузера не скроллится при любом количестве событий в логе. Лог прокручивается внутри своей области. Боевой лог визуально разделён по ходам. Правая панель переключается табами.

## Phase 2: Action Bar Redesign

Core-панель внизу (атака, рывок, отход, уклонение, конец хода). Кнопки-категории (инвентарь/зелья, классовые умения) открывают drawer/popup над панелью. Визуальное разделение по типу действия (action / bonus action / reaction). Потраченные типы — серые. Budget display интегрирован в панель.

**Верифицируем:** В бою видны core-кнопки + категории. Клик по категории — всплывающий список. После траты bonus action все bonus-кнопки серые. Работает для Fighter (Second Wind в bonus) и Rogue (Cunning Action).

## Phase 3: NPC Inspect Card

Поле `description` на Npc/MonsterTemplate в content-моделях + YAML контенте. Кнопка "осмотреть" в Perception-панели открывает карточку NPC: имя, раса, описание, фракция, HP-бар (если в бою), кнопки действий (торговать — если merchant, атаковать). Карточка — модал или slide-over panel. Backend отдаёт данные через awareness или отдельный query.

**Верифицируем:** Клик "осмотреть" на NPC → карточка с описанием и фракцией. У торговца — кнопка "торговать" ведёт к TradePanel. Кнопка "атаковать" инициирует бой. Description из YAML отображается.
