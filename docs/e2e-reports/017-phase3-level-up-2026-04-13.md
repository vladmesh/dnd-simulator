## Quick Fixes Applied

- `NpcContent.xp_value` (default 0) added to `src/dnd_simulator/content_loader/schemas.py` and propagated through `_to_npc` in `src/dnd_simulator/content_loader/creatures.py`. Previously NPCs always had `xp_value=0` so kills granted no XP — only monsters spawned from `MonsterTemplate` rolled `xp_for_cr`. The new arena world relies on hand-tuned hostile NPCs (so the player can be placed adjacent at session start with no master-spawn scripting), which made this gap a blocker. Change is backwards-compatible: existing NPCs default to 0, no behavior change for `test_vale` / `sword_vale`.
