# Frontend для отладки D&D Simulator

## Context

Проекту нужен минимальный web UI для отладки — возможность управлять сессиями, создавать персонажей и играть без CLI. REST API уже полностью готов (`/api/master/*`, `/api/player/*`), фронтенд отсутствует. CORS и static files не настроены.

## Подход

Vanilla HTML + CSS + JS, раздаётся через FastAPI `StaticFiles`. Никаких фреймворков, сборщиков, npm. Тёмная тема, моноширинный шрифт — "терминальный" дебаг-стиль.

## Структура файлов

```
src/dnd_simulator/adapters/api/static/
  index.html          — точка входа: выбор роли (Мастер / Игрок)
  master.html         — панель мастера
  player.html         — интерфейс игрока
  css/
    style.css         — общие стили (тёмная тема, layout)
  js/
    api.js            — обёртка fetch для всех API-вызовов
    master.js         — логика панели мастера
    player.js         — логика игрока
```

## Изменения в бэкенде

### `app.py` — подключить static files и CORS

- Добавить `StaticFiles(directory=..., html=True)` ПОСЛЕ роутеров (чтобы `/api/*` имел приоритет)
- Добавить `CORSMiddleware` (allow all origins — для отладки)

## Экраны

### `index.html` — Точка входа
- Два варианта: "Мастер" → master.html, "Игрок" → player.html

### `master.html` — Панель мастера

Левая колонка:
- Список миров (`GET /api/master/worlds`) + кнопка "Создать сессию"
- Список активных сессий → клик переключает правую панель

Правая панель (для сессии):
- **Обзор**: время, регионы, нации, поселения (`GET /api/master/sessions/{id}`)
- **Сущности**: таблица NPC, редактирование (PATCH), спавн/удаление
- **Время**: кнопки +1h, +6h, +24h, +7d, произвольный ввод
- **Save/Load**: список сохранений, кнопки
- **Язык**: переключатель en/ru

### `player.html` — Интерфейс игрока

Верхняя панель:
- Выбор сессии (ID) + создание персонажа (форма)

Основной экран:
- **Статус** (слева): HP, AC, золото, статы, локация
- **Восприятие** (центр): описание окружения, сущности, погода
- **Лог событий** (центр, ниже): накопительный лог
- **Карта** (справа): текущая локация + соседи (кликабельные)
- **Боевой режим**: инициатива, позиции, HP врагов (если in_combat)
- **Командная строка** (низ): ввод команд (go, attack, say, look, wait, dodge, flee, move)
- Авто-polling событий каждые 2 сек

## Верификация

1. `make serve` → http://localhost:8000/ — index.html
2. Мастер: создать сессию → god-mode view → промотка времени → спавн NPC
3. Игрок: подключиться → создать персонажа → look → go → attack
4. `make check` — бэкенд не сломан
