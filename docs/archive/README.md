# Archive

Документы, которые больше не отражают текущее состояние проекта, но сохранены для истории: устаревшие брейнштормы, отвеченные опросники, одноразовые отчёты.

Актуальные рабочие документы живут в `docs/` и `docs/brainstorms/` — то, что здесь, **superseded** и не поддерживается.

- `brainstorms/` — ранние брейнштормы, перекрытые более поздними решениями (см. живые в `docs/brainstorms/`).
- `plans/` — закрытые планы.
- `vision-questions.md` — отвеченный опросник по продукту; ответы вошли в [../VISION.md](../VISION.md).
- `flaky-test-report-WorldEditor.md` — разовое расследование флака теста (закрыто).
